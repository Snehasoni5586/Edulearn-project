Loops in Python

What is a Loop?

A loop is used to repeat a block of code multiple times.

Types of Loops

  • For Loop
  • While Loop

For Loop

for i in range(5):
    print(i)

Output:

0
1
2
3
4

While Loop

i = 1

while i <= 5:
    print(i)
    i = i + 1

Output:

1
2
3
4
5

Summary

  • For loop is used to repeat code for a specific range.
  • While loop runs while a condition is true.
