Variables and Data Types

What is a Variable?

A variable is used to store data in a Python program.

Example

name = "Sneha"
age = 20

Python Data Types

  • String - "Hello"
  • Integer - 10
  • Float - 10.5
  • Boolean - True or False
  • List - [1, 2, 3]

Example Program

name = "Sneha"
age = 20

print(name)
print(age)
