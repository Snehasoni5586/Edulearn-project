3. Excel for Data Analytics

Excel is commonly used for data analysis and reporting.

  • Tables
  • Formulas
  • Functions
  • Charts
  • Pivot Tables

4. Python for Data Analytics

Python is widely used for data analysis and visualization.

  • NumPy
  • Pandas
  • Matplotlib
  • Seaborn

Example

import pandas as pd

data = [10, 20, 30, 40]
df = pd.DataFrame(data)

print(df)
